# Security policy

## Supported versions

Security fixes target the latest release on the default branch. Earlier
versions are not maintained independently.

## Reporting a vulnerability

Do not publish credentials, exploit details, or private user information in a
public issue. Use GitHub’s private vulnerability reporting flow from the
repository’s **Security** tab.

For non-sensitive reliability or browser compatibility problems, open a normal
bug report. This project does not require visitors to create an account and is
not intended to collect personal data.
