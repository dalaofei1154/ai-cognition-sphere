# Names and marks

“AI Cognition Sphere”, “AI 认知边界球体”, and the project’s identifying icon
are used to identify Flynn’s original project.

You may use these names to truthfully describe compatibility, attribution, or
the origin of a fork. You may not use them in a way that suggests that a
modified version is official, endorsed by Flynn, or the original work.

Forks should use a visibly distinct project name and icon unless they are
submitted back to this repository and accepted as part of the official
project. Nothing in the software or content licenses grants trademark rights.
